#Stillus em Drywall

 Site institucional moderno, elegante e responsivo desenvolvido para a Stillus em Drywall, combinando a precisão da construção em drywall com soluções de automação e acabamento de alto padrão.



Sobre o Projeto

O projeto foi desenvolvido com foco em conversão e apresentação de portfólio. Ele conta com uma identidade visual sofisticada (tons de preto e dourado), navegação fluida (*smooth scroll*), seções de apresentação institucional, portfólio de projetos e canal de contato direto.


Este projeto foi construído utilizando tecnologias modernas e leves, sem dependência de frameworks pesados:

* **HTML5**: Estruturação semântica e acessível das páginas.
* **CSS3**: Estilização avançada com Flexbox, Grid Layout, variáveis CSS (Custom Properties) e design responsivo.
* **JavaScript (Vanilla)**: Interatividade, menu mobile e efeitos de rolagem suave.
* **Google Fonts**: Tipografia com fontes *Poppins* e *Playfair Display*.
